# MVP Design

## What is the MVP?

For MessMate, I would start with a simple version instead of building all the features at once.

The main goal of the MVP is to make it easy for students to rate their food and give quick feedback.

## MVP Features

The first version would include:

1. Today's menu
2. Meal rating
3. Written feedback
4. Basic feedback summary

## Basic Product Flow

The user flow would be:

**Open App → Check Today's Menu → Eat Meal → Give Rating → Add Feedback → Submit**

For example:

**Rajma → 4/5 → Good taste → Submit**

## Why These Features?

I selected these features because they directly solve the main problem.

Students can quickly rate their food, while the collected feedback can be used to understand which meals are performing well and where problems are occurring.

## What I Would Not Build Initially

I would not include advanced recommendations, notifications or a complex dashboard in the first version.

These features can be added later after understanding whether students regularly use the basic feedback system.

## Success of MVP

The MVP would be considered useful if students:

- Give feedback regularly
- Find the rating process easy
- Use the product for different meals
- Provide useful written feedback

The next product decisions would be based on this usage and feedback.
